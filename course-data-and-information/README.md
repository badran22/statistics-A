# קורס: מידע ונתונים — מערכי שיעור מלאים

מאגר מערכי שיעור מקצועי ויישומי לקורס **מידע ונתונים**, המדגיש אוריינות נתונים, חשיבה ביקורתית, פרשנות ממצאים והצגת נתונים. כל יחידה בנויה לפי מבנה אחיד וכוללת פעילות מעשית, שילוב כלי AI, התאמות ללומדים מתקשים ומחוון הערכה.

## מבנה המאגר

```
course-data-and-information/
├── README.md                 # הקובץ הזה — אינדקס ומדריך שימוש
├── unit-01-mavo.md           # מבוא למידע ונתונים
├── unit-02-types.md          # סוגי נתונים ומשתנים
├── unit-03-collection.md     # איסוף נתונים ומקורות מידע
├── unit-04-cleaning.md       # ניקוי וסידור נתונים
├── unit-05-frequency.md      # טבלאות שכיחות וסיכום נתונים
├── unit-06-center-spread.md  # מדדי מרכז ופיזור
├── unit-07-charts.md         # גרפים והצגה חזותית של נתונים
├── unit-08-infographics.md   # אינפוגרפיקה והצגת מסר מבוסס נתונים
├── unit-09-relationships.md  # ניתוח קשרים בין משתנים
├── unit-10-bias-quality.md   # הטיות, אמינות ואיכות נתונים
├── unit-11-ai-tools.md       # שימוש בכלי AI לניתוח נתונים
├── unit-12-final-project.md  # בניית דוח מסכם / פרויקט גמר
└── data/                     # קבצי נתונים לדוגמה לשימוש בפעילויות
```

## מבנה אחיד לכל יחידה

1. שם היחידה
2. מטרות היחידה (ידע / מיומנות / חשיבה ביקורתית / יישום)
3. תוצרי למידה
4. מושגים מרכזיים
5. פתיחה לשיעור
6. מהלך השיעור (שלבים א'–ה')
7. פעילות מעשית
8. שילוב כלי AI
9. התאמות ללומדים מתקשים
10. שאלות לדיון
11. מטלת בית / משימת המשך
12. הערכת למידה
13. מחוון הערכה (4 רמות)
14. סיכום היחידה

## כלים דיגיטליים מומלצים לקורס

| כלי | שימוש עיקרי | רמת קושי |
|---|---|---|
| **Google Sheets / Excel** | טבלאות, מדדים, גרפים בסיסיים | מתחילים |
| **Python (pandas, matplotlib)** | ניתוח וגרפים מתקדמים | מתקדמים |
| **כלי BI (Power BI / Looker Studio)** | דשבורדים אינטראקטיביים | בינוני |
| **כלי AI (Claude / ChatGPT)** | ניסוח שאלות, הסבר משתנים, בדיקת מסקנות | כל הרמות |

> **עיקרון מנחה:** ה-AI הוא כלי עזר לחשיבה ולא תחליף להבנה עצמאית. הלומד מנסח, מפרש ומבקר — ה-AI מאיץ ומלווה.
